## 知見（次セッションで参照）

### AgentCore Runtime のコンテナ管理

- JWT 認証の Runtime に対して SigV4（AWS CLI / boto3）は使えない（`Authorization method mismatch`）
- `stop-runtime-session` は OAuth Bearer Token で HTTPS リクエストすれば呼べる（検証済み）
- WebUI の「New」ボタンはコンテナ再起動と無関係（React 再マウントのみ）
- デプロイ後のコード反映はアイドルタイムアウト（約 15 分）待ち

### LoopGuard

- 成功した呼び出しをカウントすると正常なスライド生成で誤検知する
- エラー時のみカウントに変更済み。`max_tool_calls=300` が最終防衛線

### Composer の MCP 接続

- 各グループが独立した MCPClient を持つ（`composer_mcp_factory()` で生成）
- リトライ時に MCPClient を再生成するように修正済み（`475dd65`）
- `vibe` モードは `use_composer=True` なので、Parallel agents トグルに関係なく Composer が動く
